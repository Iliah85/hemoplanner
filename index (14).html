📲 نصب روی دسکتاپ

بهترین روش برای فایل HTML محلی:

ویندوز — میانبر اپ (پیشنهادی)

  1. فایل HTML را در یک پوشه ثابت بگذار (مثلاً Documents\دفترچه-رشد)
  2. فایل نصب-روی-دسکتاپ.bat را کنار همان HTML بگذار و اجرا کن
  3. یا دستی: روی دسکتاپ راست‌کلیک → New → Shortcut و این را بگذار:
    chrome.exe --app="file:///C:/مسیر/کامل/personal-growth-planner-v4.html"
  4. نامش را بگذار «دفترچه رشد» — مثل یک برنامه واقعی بدون نوار آدرس باز می‌شود

مک

  1. فایل HTML را در پوشه ثابت بگذار
  2. Terminal را باز کن و بزن:
    open -a "Google Chrome" --args --app="file:///Users/YOU/path/personal-growth-planner-v4.html"
  3. یا از فایل نصب-روی-دسکتاپ.command استفاده کن

Chrome / Edge — نصب رسمی PWA

اگر فایل را با یک سرور محلی باز کنی (نه file://)، منوی ⋮ → Install app در دسترس است. برای سرور محلی در همان پوشه:

python -m http.server 8080

بعد برو به http://localhost:8080 و Install بزن.

موبایل

Safari: Share → Add to Home Screen
Android Chrome: منوی ⋮ → Install app / Add to Home screen
